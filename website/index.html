The Architecture Studio

Project 11

The following is: A dual-panel AI-powered diagramming tool that generates professional infrastructure diagrams from plain-language descriptions. Describe your on-premises data center in the left panel and your AWS architecture in the right panel. Each panel generates a detailed SVG diagram independently. Once both diagrams are ready, click Generate Migration Analysis for a side-by-side component mapping, key business benefits, and a phased migration roadmap — all generated automatically by Amazon Bedrock.

Left Panel
Describe your on-premises infrastructure to generate a data center diagram
Right Panel
Describe your AWS architecture to generate a cloud diagram

On-Prem to AWS Translator

Project 12

The following is: An AI-powered translation tool that reads your on-premises infrastructure description and instantly generates a detailed AWS architecture recommendation. It maps every on-premises component to its AWS equivalent, produces a ready-to-use AWS architecture description you can copy directly into a diagramming tool, and delivers a full migration analysis with component mapping, business benefits, and a phased migration roadmap. Includes a one-click button to open The Architecture Studio with your description already copied to clipboard.

Input
Plain-language description of your on-premises infrastructure
Output
AWS description, component mapping, benefits, and migration roadmap
Auto-Translation Migration Analysis Copy to Clipboard Links to Studio Powered by Bedrock

AWS Architecture Catalog

Project 13

The following is: A browsable reference catalog of the most common AWS architecture patterns organized into 8 categories. Each architecture includes color-coded service tags, a plain-English description of what it solves and why it’s commonly used, and a detailed numbered traffic flow walkthrough from the user’s perspective. Diagrams with official AWS icons are included for every architecture.

Categories
AI & ML, Web & API, Data & Analytics, Security, Networking, Containers, Serverless, Disaster Recovery

Each service card shows the official AWS icon, service number, name, and a plain-English definition. Search filters across all tiers in real time by service name or description.

Course Spec Builder

Project 15

The following is: A client-side course discovery questionnaire that walks a requestor through 12 sections and ~150 questions covering business need, target audience, learning objectives, scope, delivery format, assessment, and more. Progress auto-saves to localStorage. On completion, generates two downloadable files: a plain-language PDF of all questions and answers, and a structured Markdown course specification ready for the course developer.

Input
12-section guided questionnaire — business need, audience, objectives, scope, delivery, assessment
Output
PDF of Q&A for the requestor + Markdown course spec for the developer
